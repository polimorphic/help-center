---
title: "Create charts, tables, and documents in the Assistant"
description: "Ask the Assistant for charts and tables in the chat, or for Word, PDF, and Excel files you can download."
---

When you're preparing a report, a council memo, or a quick update for your manager, you often need more than a written answer. The Assistant can show your information as a chart or table right in the chat, or put it into a Word, PDF, or Excel file you can download and share.

## Show a chart or table in the chat

1. Open the Assistant.
2. Ask for the chart or table you need, such as *Make a bar chart of open cases by status* or *Show a table of this month's permit applications with the applicant and due date.*
3. Send your message.

The chart or table appears in the Assistant's answer. Charts can be bar, line, pie, or scatter charts. If you don't name a type, the Assistant picks one that fits.

- To save a chart, hover over it and select **Download chart as PNG**.
- To save a table, select **Download as CSV** above it.

**Tip:** If the chart isn't quite right, ask for a change in the same chat, such as *Make that a pie chart* or *Only include the last 90 days.*

## Create a Word or PDF document

1. In a chat, ask for a document and say which kind you'd like, such as *Put this summary in a Word document* or *Turn this into a one-page PDF.*
2. Send your message.

The Assistant writes the document and attaches it to its answer as a file card. If you don't say which kind you want, you get a PDF. Pick Word when you plan to edit the file, and PDF when it's ready to share or print.

You can ask for charts inside the document too, such as *Write a PDF report on this quarter's requests with a line chart of requests by month.* Charts appear as images in the document.

## Create or edit an Excel workbook

1. In a chat, ask for a spreadsheet, such as *Export these cases to Excel with a total for each status.*
2. To change a workbook you already have, attach it first and describe the change, such as *Add a summary tab with totals by department.*
3. Send your message.

The Assistant attaches the workbook to its answer. It can add native Excel charts and formulas, such as a total that updates when you change the numbers. It can also build a summary table grouped by a column. The summary uses formulas, not an interactive Excel pivot table.

When you edit an attached workbook, everything already in it is kept. If an edit could lose charts or images that are already there, the Assistant tells you it can't edit the file safely and offers to build a new one instead.

## Preview and download a file

1. Select the file card in the Assistant's answer.
2. Word, PDF, and PowerPoint files open in a preview next to the chat. On a smaller screen, the preview opens on top of the chat.
3. Optional: select the expand button to view the file full screen.
4. Select the download button to save the file.

To close the preview, select the X or press **Esc**. The file card stays in the chat, so you can open it again later. You can also select the download button on a card to save the file without opening the preview. Excel files show *No preview available*, so download them to open them in Excel.

## Good to know

- The Assistant makes one file per answer. If you need several, ask for them one at a time.
- When you ask for a change to a file, the Assistant makes a new version and attaches it to its new answer. The earlier file stays in the chat.
- Formulas in an Excel workbook calculate when you open the file.
- Always review a file before you share it outside your team.
