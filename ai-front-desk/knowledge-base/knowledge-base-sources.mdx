title: "Knowledge base sources"
---

If residents are hearing an old fee or a deadline that's already passed, the cause is almost always a source. Knowledge sources are the pages, files, and other content the AI uses to answer questions, and the AI can only answer as well as they do. A clear, current source gives residents a clear, current answer.

You manage all of them on the **Knowledge Base** page.

## How sources work

### Where sources live

Select **Knowledge Base** under **AI Front Desk** in the left menu. Each tab holds one kind of source: **Links**, **Documents**, **Domains**, **FAQs**, **Workflows**, **Transfer Lines**, **GIS Layers**, and **Integrations**.

### Who can see a source

Each link, document, [FAQ](/getting-started/glossary), and domain has an **Availability** setting:

- **Everyone**: residents can get answers from it on chat, voice, and search. Staff tools can use it too.
- **Staff only**: only staff-facing tools use it. Residents never see it.

Setting a whole domain to **Staff only** applies to every page crawled from it, including pages crawled before the change.

### Take a source out of answers

Archiving a source takes it out of AI answers without deleting it. You can restore it later. When you restore web pages, Polimorphic reads them again so the current content comes back. Restored documents return as they were stored. To use a newer version of a file, upload it again.

### Citations

Turn off **Refer to source in response** on a source if you'd like it to shape answers without being linked. FAQs, transfer lines, and map layers never show as links because there's nothing for a resident to open.

### Tags

You can add tags to a link or document. Tags you add by hand count more in search than tags Polimorphic generates. A tag helps a source show up for the right questions, but it doesn't guarantee the AI will use it.

To tag a source, follow these steps:

1. Go to [Knowledge Base](/getting-started/glossary), and select Links or Documents based on the source you want to tag
2. Search for the source using the search bar
3. Click the pencil icon on the far right side of the page
4. Add your tags one by one, clicking enter after each tag
5. Save in the bottom right corner

### Keeping sources current

Crawled websites can refresh on a schedule you pick. Uploaded documents and FAQs don't change until you edit or replace them.

## Example: getting ready for permit season

The building department in Clearwater County is updating its fees for spring. The department head:

1. Uploads the new *2027 Building Permit Fee Schedule* PDF and sets it to **Everyone**.
2. Archives the 2026 fee schedule so the AI stops quoting old fees.
3. Adds an FAQ, "Do I need a permit for a shed?", because residents ask it often and the answer is buried in the code.
4. Uploads an internal inspection checklist as **Staff only**, so inspectors can ask the staff assistant about it but residents can't.
