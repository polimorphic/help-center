---
title: "Improve a wrong or weak answer"
---

When a resident or coworker tells you the AI got something wrong, you can usually trace the answer back to a source and fix it for good. Start with roughly when the conversation happened and what the resident asked.

## Find the conversation

1. Select **Log** under **AI Front Desk** in the left menu.
2. Filter by **Date** and **Interaction Type** to narrow the list.
3. Open the conversation.
4. Read the answer and the sources it used.

## Note what went wrong

1. Select the thumbs-down icon on the answer.
2. In **What went wrong?**, describe the problem, such as *Quoted the 2025 fee*.
3. In **The ideal answer - include any relevant links**, write what the AI should have said.
4. Select **Submit**.

Your feedback is saved with the conversation.

## Fix the cause

Pick the row that matches what you found.

| What you found | What to do |
| --- | --- |
| The source has the wrong information | Correct the web page or document first. Then, on the **Knowledge Base** page, open the source with the edit icon, turn on **Refresh this source in the AI index**, and select **Save**. |
| An old document is still live | Archive the old document. Upload the current version. |
| The right source exists but wasn't used | Edit the source and use **Add tag** to add words residents use, such as *dog registration*. You can also write an [FAQ](/getting-started/glossary) for the exact question. |
| No source covers the question | Add a link, document, or FAQ that answers it. |
| The answer needed an address but didn't use your map | Check that the right [GIS](/getting-started/glossary) layer exists and has the field the answer needs. |
| The source is staff-only | If residents should get this answer, change **Availability** to **Everyone**. |
| The answer looks thin but the source is complete | Ask the question again in test mode. Searches can time out when the system is busy. If the gap repeats, the source needs work. |

## Make sure the fix worked

1. Return to the conversation in **Log**.
2. Select **Add to Health Check** so this question is tested from now on.
3. Run a health check, or ask the question again in test mode.

The AI gives the corrected answer, and the question stays in your health check so you'll notice if it breaks again.
