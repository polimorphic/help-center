---
title: "Publish the widget to your website"
---

Once the [AI Front Desk](/getting-started/glossary) is ready, the last step is putting it where residents will find it: your website. You'll copy a small piece of embed code for the chat or search bar and hand it to whoever manages your site.

## Before you begin

- Loop in someone who can edit your website, such as your web team or website vendor.

## Add the chat widget

1. Select **Settings**, then **Channels**.
2. Open the **Chat** tab.
3. Turn **Show Greeting** on or off. The greeting is the small bubble next to the chat button.
4. Turn **Show Borders on Greeting** on or off.
5. Use the position switch to put the chat button on the right or left of the page.
6. In **Icon Size**, pick a size or select **Custom** to enter one.
7. If you've set a custom chat icon, turn **Use Icon Container** on or off to show or hide the container around it.
8. Select **Copy Embed**.
9. Send the code to your web team and ask them to add it to every page where the chat should appear. Most website systems have a place for site-wide code.

Once the code is live, the chat button shows on those pages.

## Add the search bar

1. Open the **Search** tab.
2. Pick the option that fits your website, such as **Polimorphic Search**, or the option that replaces your current site search, such as **Replace CivicPlus Search**.
3. Select **Copy Embed**.
4. Send the code to your web team with the page where the search bar should go.

Once the code is live, the search bar shows on that page.

## Test it before and after it goes live

- Before the code goes live, select **Open Chat in Test Mode** or **Open Search in Test Mode**. To share a test with a coworker, select **Copy Chat Test Link** or **Copy Search Test Link**. These conversations show up in test logs.
- After your web team adds the code, open your website in a private browser window and ask a question.

## When you need to copy the code again

| Change | Copy the embed code again? |
| --- | --- |
| Name, opening message, disclaimer, or suggestions | No. Select **Publish Changes** on the customization page. |
| Knowledge sources, [FAQs](/getting-started/glossary), or transfer lines | No |
| Chat icon, **Icon Size**, **Use Icon Container**, colors, font, corner radius, or chat size | Yes |
| Greeting bubble, greeting borders, or button position | Yes |

When it's all set, residents can ask questions from your website, and their conversations show up in **Log**.
