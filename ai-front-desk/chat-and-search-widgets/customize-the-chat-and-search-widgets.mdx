---
title: "Customize the chat and search widgets"
description: "Change the name, messages, colors, font, icon, and search layout residents see on your website."
---

Residents should feel like they're talking to your organization, not a generic chatbot. On the **Chat & Search Customization** page, you can match the chat and search widgets to your website and set what residents see first.

## Open the customization page

1. Press **Ctrl+K** (**Cmd+K** on a Mac) to open the command menu.
2. Type *Customize* and select **Customize**.

A live preview sits next to the settings. Use the **Chat** and **Search** buttons at the top to switch between the two widgets. The preview updates as you make changes.

## Set the name, logo, and font

Under **General Settings**:

- **Name** is the name residents see at the top of the chat. If you leave it blank, it uses your organization's name.
- **Organization Logo** and **Banner** take an SVG, PNG, or JPG image up to 3 MB.
- **Font Family** sets the font for the chat and search widgets.
- **Corner Radius** controls how rounded the chat window, message bubbles, and buttons are.

## Pick your colors

Under **Colors**, set the **Header & Button**, **Header Text**, and **Link Text** colors.

Each color pair shows a **WCAG AA Contrast Check** with its contrast ratio. If a check doesn't pass, pick a darker or lighter color so residents can read the text easily. See [Accessibility](/security-privacy-and-compliance/accessibility).

## Write the opening messages

Under **Messages**, you can change three messages. Leave any of them blank to use the default text.

| Message | What it's for | Default |
| --- | --- | --- |
| **Opening Message** | The first thing residents see when they open the chat | *Hi, how can I help?* |
| **Language Message** | Lets residents know they can ask in their own language | A note that residents can ask in their language of choice, with a list of supported languages |
| **Disclaimer** | A reminder that AI answers should be checked | *AI can make mistakes. Please confirm important information.* |

## Change the chat icon, size, and feedback

Under **Chat Settings**:

- **Chatbot Icon:** Pick **Use default icon**, or pick **Upload custom icon** and add your own image.
- **Chat Size:** Pick **Small**, **Medium**, or **Large**.
- **Enable Feedback Collection:** Turn this on to let residents leave a written comment when they mark an answer as not helpful.

## Set up the search widget

Under **Search Settings**:

- **Elements to display:** Pick what appears at the top of the search page: **Header**, **Image**, or **Banner**. If you show the banner, you can add **Banner Text**.
- **Layout:** Pick **Combined view**, **Tabbed view**, or **Results only view**.
- **Suggestions:** Show suggested searches as a **Dropdown** or as **Chips**. Under **Search Suggestions**, type each one and select **Add a suggestion** for more.
- **Backup Website Search URL:** Enter the address of your website's own search, such as *https://www.example.com/search*. When residents don't find what they need, the search widget offers them a link to search your website instead.

## Publish your changes

1. Check the preview for both **Chat** and **Search**.
2. Select **Publish Changes**.

You'll see *Settings saved successfully*. Changes to the name, messages, and suggestions show on your website right away.

**Tip:** Some changes, like the chat icon, colors, font, corner radius, and chat size, only show on your website after you copy the embed code again. See [Publish the widget to your website](/ai-front-desk/chat-and-search-widgets/publish-the-widget-to-your-website#when-you-need-to-copy-the-code-again).
