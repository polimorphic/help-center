New to Polimorphic, or not sure what a term means? Here are the words you'll see in the product and in this help center, in alphabetical order.

## Terms

| Term | Meaning |
| --- | --- |
| Access Control | The settings area where administrators manage staff members, groups, and roles. Roles decide what each staff member can see and change. |
| Activity | The tab on a case that shows its full history in time order: notes, emails, calls, form submissions, payments, documents, and system events. |
| AI Front Desk | The part of Polimorphic that answers residents' questions through website chat, site search, and phone, using your knowledge base. |
| Assistant | The private AI chat for staff. It answers questions from your organization's information and can create charts, documents, and slide decks. See [What is the Assistant?](/assistant/what-is-the-assistant). |
| Assignee | A staff member responsible for a step or task on a case. Assignees can be notified by email. |
| Case | The record of one resident request, such as a permit renewal or a pothole report. A case holds forms, files, payments, messages, and notes. |
| Case manager | The staff member who owns a case overall. Each case can have one case manager. |
| Case member | A person who has been added to a case and can see it, such as a co-applicant or a contractor. |
| Case requester | The resident or organization the case is for. The requester usually receives the case's emails. |
| Case status | Where a case stands: Unsubmitted, Open, Closed, Archived, or Hidden. See [Case statuses and the document center](/working-in-polimorphic/cases/case-statuses-and-the-document-center). |
| Contact | The record for one person or organization. A contact shows their details and every case and interaction linked to them. |
| Contact book | Your organization's full collection of contacts. |
| FAQ | Frequently asked question. In Polimorphic, an FAQ is a question and answer you add to the knowledge base so the AI answers it the way you want. |
| Form | A set of questions in a workflow step. Residents fill out forms to apply or report something. Staff can fill out internal forms that residents never see. |
| Form letter | A saved email template you can apply when you write to a resident. |
| GIS | Geographic information system. A GIS layer is map data, such as trash pickup zones or council districts, that Polimorphic can use to answer address-based questions. |
| Group | A set of staff members who share the same roles, such as "Permit Technicians." Groups can be managed by your SSO provider. |
| Interaction log | A record of one conversation between a resident and the AI Front Desk. You find logs under **Log** in the sidebar. |
| Knowledge base | The web pages, documents, FAQs, and other sources the AI uses to answer residents. |
| My To-Do | The default tab on the Cases page that shows cases waiting on you. |
| Note | An internal comment on a case. Residents never see notes. You can @-mention a coworker to notify them. |
| Outbound communication | An email or text message (SMS) sent to many contacts at once. |
| Role | A set of permissions, such as "can view and edit cases." Administrators give roles to groups. |
| SSO | Single sign-on. A way to sign in to Polimorphic with your organization's work account, such as Microsoft. |
| Step | One stage in a workflow, such as a form, a payment, an email, or a status change. A step opens when the steps before it are done. |
| Tag | A label you add to cases or contacts to group and filter them, such as "Downtown" or "Rush." |
| Task | A one-off to-do on a case, with a name, assignees, and an optional due date. |
| Workflow | The set of steps for one type of request, such as a building permit renewal. Every case of that type follows the workflow. |
| Your Turn | A label in the Cases table that marks cases where you're assigned to the current step. |
