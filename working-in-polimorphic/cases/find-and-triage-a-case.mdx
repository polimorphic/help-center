---
title: "Find and triage a case"
---

At the start of the day, or whenever new requests come in, you'll want to see what needs you and pick what to work on first. Here's how to find your [cases](/getting-started/glossary), sort out what's urgent, and get each one moving.

## Find the cases that need you

1. Select **Cases** in the left sidebar.
2. Select the **My To-Do** tab to see cases waiting on you, or **All Cases** to see every case you can access.
3. Select the filter button and pick filters, such as **Status**, **Workflow**, **Tags**, **Step Assignee**, or **Next Due Date**.
4. To reuse these filters later, select **Save as new view**, enter a **View name** such as *Overdue renewals*, and save it.
5. To see cases on a map, select **Map view**. Select **Table view** to go back.

The table shows only the cases that match your filters, and saved views appear as tabs you can come back to.

## Pick which case to work first

1. Look at the **Next Due** column. Cases marked **Overdue** or **Due today** come first.
2. Look for the **Your Turn** label in the **Assignees** column. It means you own the current step.
3. Check the **Progress** column to see how far each case has moved through its [workflow](/getting-started/glossary).
4. Select a case name to open it.

## Get a case moving

1. Read the case summary and the **Case Requester** card at the top of the case.
2. Select the **Details** tab to read what the resident submitted.
3. Select the **Activity** tab to see what's already happened.
4. In the tasks area, select **My work** to see the steps and tasks assigned to you.
5. Open the active step and complete it, or take the next action, such as sending an email.
6. If the case needs a deadline, open the task's menu and select **Add due date**.
7. If someone else should handle it, open the task's menu and select **Manage Assignees**.
8. If the case is resolved, select its status at the top of the case and pick **Closed**.

The case now has a clear next step, owner, and due date, and every change you made shows on its **Activity** tab.

## Tips

- Select **Refresh** above the table to load new cases without leaving the page.
- To close several resolved cases at once, select them in the table and choose **Close cases**.
- Test cases are hidden by default. Use the **Include test cases** filter to show them.
