<Update label="November 1, 2026" description="Release notes">

### Improvements

**AI assistant**

- **The Assistant chat layout** is cleaner. Attached files show as file cards, the reply box fits on one row with a + button for attachments, and the chat history sidebar puts New chat and Search at the top.
- **Voice dictation in the Assistant** lets staff speak a prompt instead of typing it. Select the microphone in the chat box, and the transcript appears in the input so you can edit it before sending.
- **Charts in Assistant documents** are now supported. When the Assistant creates a Word or PDF document, it can add bar, line, pie, and scatter charts, including in documents built from your Word templates.

**Knowledge base**

- **Websites monitored for changes** now also add the PDFs linked from their pages to your knowledge base. Edits to their crawl settings now apply right away.

**Settings**

- **GIS layers and transfer lines** now have their own pages in Settings, so staff can manage them without opening the knowledge base. Both are also searchable from the command palette.

**Cases**

- **Case manager assignment emails** now go out when a case manager assignee block configuration assigns someone, not only when staff assign a case manager by hand.
- **Send test email** in communication blocks lets staff email the rendered message to themselves to check it before residents receive it. No case is needed.

**Payments**

- **The Payment type filter** on the Transactions page and in the batch action dialog now lists each workflow once and includes payments from every version of it.
- **Springbrook exports** now include only the gross payment amount. The separate fee row is gone, so staff no longer need to delete it before importing.

### Fixes

**AI assistant**

- **AI chat responses** no longer fail with an "unable to process your request" message during platform updates.

**AI phone and voice**

- **Calls from international or unrecognized phone numbers** are now fully recorded in the AI interaction log.

**Cases**

- **The cases list** now loads even when a contact has an email address in an unusual format. Previously, one such record could leave the list and case count empty.
- **Public workflow application pages** now show the current stages and fees, and new applications start on the latest live version of the workflow.

</Update>
