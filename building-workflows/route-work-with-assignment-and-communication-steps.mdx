---
title: "Route work with assignment and communication steps"
---

A [case](/getting-started/glossary) moves faster when the right people hear about it at the right time, and nobody has to remember to forward an email. [Assignees](/getting-started/glossary), role steps, and message steps handle that for you inside the [workflow](/getting-started/glossary).

## Before you begin

- Work in a draft of the workflow.
- Think about who handles each step, and who only needs to know about it.

## Assign a step to staff

1. Open the workflow and select **Edit Workflow**.
2. Select the step.
3. Select **Add assignees**.
4. Pick a person or team, such as the code enforcement office.
5. Select **Assign & Notify** if they'll do the work. Select **Notify Only** if they only need to know.
6. Select **Save**.
7. Optional: under **Time to Complete**, enter hours or minutes to get a reminder if the step stays open too long.

When a case reaches this step, the people you added get notified.

## Set the case manager or requester

1. In **Add Steps**, select **Assign Case Role**.
2. Pick **Case Manager** or **Case Requester**.
3. Pick the person.

When a case reaches this step, that person is set in the role on the case. If you set a [case manager](/getting-started/glossary), they get an email letting them know the case is theirs.

## Send an email from the workflow

1. In **Add Steps**, select **Send Message**. New message steps are named "Send Email."
2. Pick a sender in **From**.
3. Select **Add recipient…** and pick who gets the message, such as the applicant.
4. Enter the **Subject**.
5. Write the message. Use **Insert Variable** to add answers from the form, such as the property address.
6. Optional: to have the AI write the message from the case details, pick **AI generated** instead of **Custom**.
7. Optional: under **Attachments**, add files or **Case Documents to Attach**.
8. Optional: in **Preview**, select **Send Test** to email the message to yourself and check how it looks.
9. Under **Sending method**, pick **Automatic** to send right away, or **Manual** to have staff review it first.

When a case reaches this step, the message goes out, or waits as a task for staff to review.

## Tag the case

1. In **Add Steps**, select **Add Tag**.
2. Pick Add or Remove.
3. Pick the tag, such as *Needs inspection*.

When a case reaches this step, the tag is added or removed.

## Turn on case emails for the whole workflow

1. Open **Workflow Settings**.
2. Under **Notify When**, turn **Case is opened**, **Case is closed**, or **Email is received** on or off.

Emails go out for the events you turned on, on every case in this workflow.

**Tip:** Create a test case and walk it through each step to check who gets what before you publish.
